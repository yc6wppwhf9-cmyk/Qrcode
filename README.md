# Priority Bags Link Tree QR

A simple static QR landing page for all social handles.

## How to customize

1. Open `script.js`.
2. Update the `socials` array if you add or change social handles.
3. Add the real logo image at `assets/logo.png`.
4. Deploy the folder to any static host such as GitHub Pages, Netlify, Vercel, or your website.
5. Open the deployed URL, paste that same public URL into the QR destination field, click **Update QR**, then **Download PNG**.

Expected GitHub Pages URL:

`https://yc6wppwhf9-cmyk.github.io/Qrcode/`

The QR code must point to a public URL. A local file path will open only on your own computer, not on someone else's phone.

## Local preview

Open `index.html` in a browser, or run a static server from this folder.
